Telelogs now reads Kubernetes. Run the server with `--kubernetes` and every pod's logs stream into the app next to your Docker containers, archived to your bucket like everything else.

## Kubernetes

- `--kubernetes` reads every container of every pod, from your kubeconfig's current context or, inside a cluster, from the pod's service account. `--kube-context`, `--namespace` (comma separated) and `--selector` (label selector) narrow it down.
- Pods are followed from their first line as they start, containers are followed again after a restart, and the app marks them running, waiting, exited or removed.
- Each container shows as `namespace/pod/container`, with namespace, pod, container, node, app and image labels on every line. In lists it's shortened to the app and the pod's suffix, so replicas stay distinct: `auth-svc-t2xv7`, `kong-gateway-7d79c/proxy`.
- A server can read Docker and Kubernetes at once; if one is unreachable it keeps serving the other. `--no-docker` makes a cluster-only server. Containers that Kubernetes runs on the same Docker daemon (Docker Desktop, OrbStack) are read once, through Kubernetes, and Kubernetes' pause containers are skipped.
- Run it inside the cluster with [`deploy/kubernetes/telelog-server.yaml`](https://github.com/tolaniverse/telelogs/blob/v0.2.0/deploy/kubernetes/telelog-server.yaml): a read-only service account (pods: get, list, watch; pods/log: get), a non-root deployment on a read-only filesystem with its token in a Secret, and a service.

```sh
kubectl apply -f https://raw.githubusercontent.com/tolaniverse/telelogs/v0.2.0/deploy/kubernetes/telelog-server.yaml
kubectl -n telelogs create secret generic telelog-server --from-literal=token=$(openssl rand -hex 32)
kubectl -n telelogs port-forward svc/telelog-server 7070
```

- In the app, **Add source → Kubernetes** turns the context, namespaces and selector you type into the server command, ready to copy.

## Better log levels

- Lines from Kubernetes components (klog: `I1002 23:47:01 …`, `W…`, `E…`) get their levels, so their warnings and errors show up under the level filters.
- Stack traces keep the level of the line that started them: Java frames, `Caused by:` and the exception line, and Python tracebacks. Filtering by **Error** shows the whole trace, not just its first line.
- Fixed a crash when a log line had a multi-byte character (accents, emoji, non-Latin text) around its 64th byte.

## Also

- `docker/Dockerfile` builds the server image from source.

Tested against a real AKS cluster (4 nodes, 99 containers): ready in about 3 seconds, around 40 MB of memory while streaming.

## Install

Same as [v0.1.0](https://github.com/tolaniverse/telelogs/releases/tag/v0.1.0): `ghcr.io/tolaniverse/telelog-server:0.2.0`, the server archives and the macOS app below, checked against `SHA256SUMS`. The app isn't notarized yet; the first time, click **Open Anyway** in System Settings → Privacy & Security.
