The first release of Telelogs: a self-hosted server that tails your Docker containers, and a native desktop app to read them, with every line archived to a bucket you own.

## What's in it

**telelog-server**
- Tails every container on a Docker host and follows new ones as they start; stopped and removed containers are marked, not dropped.
- Streams to the app over gRPC. On `127.0.0.1` it runs open; anywhere else it needs a token (`telelog-server gen-token`), and it speaks TLS with your certificate.
- Archives every line to S3, Cloudflare R2, MinIO, Google Cloud Storage or a local directory as compressed chunks, with a retention rule (`--archive-url`, `--retention-days`). Restarts resume from a checkpoint with no gap and no duplicates.

**Telelogs desktop app (macOS)**
- One live stream across containers, with text, level and time-range filters, and a JSON view.
- Picking a time range reads past the in-memory buffer into the bucket, including logs from containers that no longer exist.
- Storage screen with the bucket's size, oldest day, last write and errors.

## Install

**Server, as a container** (amd64 and arm64):

```sh
docker run -d --name telelog-server \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -p 127.0.0.1:7070:7070 \
  ghcr.io/tolaniverse/telelog-server:0.1.0 --allow-unauthenticated
```

The port is published on `127.0.0.1` only, which is why `--allow-unauthenticated` is safe here. To reach the server from other machines, drop that flag and set `-e TELELOG_TOKEN=...` instead.

**Server, as a binary:** download the archive for your platform below, then run `./telelog-server`. Linux builds need glibc 2.35 or newer.

**Desktop app:** download `Telelogs-0.1.0-macos-universal.zip` (Apple silicon and Intel), unzip, and move Telelogs to Applications. This build isn't notarized by Apple yet, so the first time macOS will refuse to open it: open **System Settings → Privacy & Security** and click **Open Anyway** next to Telelogs. It connects to `http://127.0.0.1:7070` by default; use `--server` and `--token` for anything else.

Check downloads against `SHA256SUMS`.

## Known limitations

- Docker is the only log source so far. Kubernetes and VMs (through OpenTelemetry) are next.
- The desktop app is macOS-only for now, and not yet signed with a Developer ID or notarized.
- Searching a bucket loads at most the newest 20,000 matching lines per query.
