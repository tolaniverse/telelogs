Telelogs is now on crates.io, and big clusters are easier to read: pods are grouped by namespace, and long lines wrap.

## Install with Cargo

```sh
cargo install --locked telelog-server   # the server: telelog-server
cargo install --locked telelogs         # the desktop app: telelogs
```

The app builds on macOS and needs the Xcode Command Line Tools. The libraries are published too: `telelog-core`, `telelog-proto` and `telelog-sources`.

## Kubernetes namespaces

- In the sidebar, Kubernetes pods sit under one collapsible row per namespace, so `kube-system`, `cert-manager` and the like stay out of the way. Namespaces start collapsed.
- Each namespace has a checkbox that turns all its pods on, or off when they're all on already. It shows a dash when only some are on, and each row counts `on/total`.

## Wrapped log lines

- Long messages wrap onto as many lines as they need instead of running off the edge. Time, level and source stay aligned with the first line.
- Rows show up to 2,000 characters, with `…` when cut; the detail panel still has the whole line.
- Scrolled up, the view stays on the same line while new lines arrive, filters change or old lines leave the buffer.

## Also

- The app's package is now `telelogs`, named like its command: `cargo run -p telelogs`. Its folder is still `crates/telelog-app`.
- The gRPC definition moved into its crate, at `crates/telelog-proto/proto/telelog/v1/logs.proto`.
- With the container image, generate a token with `docker run --rm ghcr.io/tolaniverse/telelog-server gen-token`.

## Install

Same as [v0.1.0](https://github.com/tolaniverse/telelogs/releases/tag/v0.1.0): `ghcr.io/tolaniverse/telelog-server:0.3.0`, the server archives and the macOS app below, checked against `SHA256SUMS`, or Cargo as above. The app isn't notarized yet; the first time, click **Open Anyway** in System Settings → Privacy & Security.
